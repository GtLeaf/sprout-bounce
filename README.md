# Happy Jump

完整开发包已内置 Three.js 和全部运行资源，不需要联网加载依赖。

## 微信小游戏版本

仓库现已包含独立的原生微信小游戏包 [`wechat-minigame`](wechat-minigame/README.md)。它使用 Canvas 运行，通过微信云开发的 `OpenID` 自动识别玩家、恢复历史成绩并维护全球排行榜；昵称和头像只在玩家点击微信原生授权按钮后保存。该版本不使用 Supabase 邮箱登录。

微信小游戏不能直接运行网页 DOM/CSS，因此 GitHub Pages 网页版与微信小游戏版分别维护。微信开发者工具的导入、AppID、云环境、集合权限和云函数部署步骤见 `wechat-minigame/README.md`。

## 启动与开发

- Windows 试玩：双击 `start-game.cmd`，浏览器会自动打开游戏。
- 命令行启动：安装 Node.js 18 或更高版本后运行 `npm start`，再访问终端显示的本地地址。
- 自动测试：运行 `npm test`。
- 发布：将 `index.html`、`game.js`、`game-rules.mjs`、`style.css`、`assets` 和 `vendor` 原样部署到任意静态网站空间。
- 项目不需要前端构建步骤；游戏账号与排行榜由可选的 Supabase 服务提供，支付与服务端权威对局逻辑尚未接入。
- 游戏主体仍是静态网页；全球排行榜使用 Supabase 提供邮箱账号、持久登录会话和云端成绩。未配置云端时会自动使用本机排行榜。

## 操作

- 电脑：使用 `WASD` 或方向键跳到相邻方块，也可以点击相邻方块。
- 手机：在棋盘任意位置滑动。短滑移动一格，保持同一方向滑动可连续跳，松手立即停止。
- 手机首次访问并点击“开始游戏”后，会在真实棋盘上出现三步引导，依次演示四向滑动、连接至少四个同色格和闪烁时撤离；引导期间暂停计时与角色操作，可左右滑动或点箭头翻页，关闭或完成后会在本机记住状态。桌面端不显示该引导。
- 角色只能向上、下、左、右移动，不能斜向移动。

## 全球排行榜

排行榜后端使用 Supabase，邮箱只用于登录，公开排行榜只返回玩家昵称、最佳分数、最高关卡和游戏局数。登录会话保存在玩家自己的浏览器中，后续打开游戏会自动恢复；断网或未登录时的成绩会先暂存本机，登录后再补传。

1. 在 Supabase 创建项目，打开 SQL Editor，运行 `supabase/migrations/202608250001_cloud_leaderboard.sql`。
2. 在 Authentication 中启用 Email 登录。建议保留邮箱验证，并将 Site URL 设为 `https://gtleaf.github.io/sprout-bounce/`。
3. 在 GitHub 仓库的 Actions variables 新建 `SUPABASE_URL`，在 Actions secrets 新建 `SUPABASE_ANON_KEY`。这里使用的是可公开的 anon/publishable key，不得使用 `service_role` 密钥。
4. 重新运行 `Deploy to GitHub Pages` workflow。未配置这两项时，页面会隐藏账号入口并回退至本机排行榜。

数据库已启用行级权限：所有人可读公开榜单，只有已登录玩家能通过 `submit_score` 函数更新自己的成绩。由于游戏本体在浏览器运行，这能防止普通越权写入，但不是强反作弊方案；竞技排位需要服务端权威游戏逻辑或对局记录验签。

## 规则

- 完整棋盘为 7×7，方块依次按橙、黄、绿、蓝、紫、红循环变色；配色保持柔和糖果感，饱和度略高于旧版，并以克制的顶面与侧面明暗保证手机小屏也容易分辨。
- 每次落地只会把当前方块推进到下一种颜色。
- 四个或更多同色方块只要通过上、下、左、右连通就会进入爆炸倒计时；直线、L 形、T 形和块状都有效，对角线接触不算连通。
- 爆炸只作用于本次落地形成的同一片连通组合，不会波及旁边独立的同色方块。
- 方块闪烁倒计时期间，玩家把周围正交连通的格子踩成同色时，新格会继承当前剩余倒计时并加入同一次爆破；进入逐格爆破后，只要还有同色爆破格未落下，继续踩出的四向相邻同色格仍会排到本次爆破尾部，并至少保留一次跳离时间。整组完全爆破后连接窗口才关闭。
- 玩家可以停在任意稳定方块上；爆炸瞬间仍在危险组合中会损失一条生命，并在安全方块复位，三条生命耗尽才会结束本局。
- 爆炸后会露出每个格子下方的绿色独立托块，空位依次消费左上角“下一组”的颜色；新方块从凹槽内由薄片向上生长，不再从棋盘上空掉落遮挡视线。
- 新补回的同色方块不会自动触发消除，必须由玩家再次落地变色后检查。
- 战役包含 8 层和入门、标准、进阶、挑战 4 个难度阶段；在限时内达到本层爆破回合目标后进入下一层。
- 关卡进度改为“爆破回合”：一组方块完全塌陷后，按最终塌陷数量每 `4` 格折算 `1` 回，`8` 格为 `2` 回、`12` 格为 `3` 回；警告或逐格爆破期间继续接入的同色格也计入本组。8 层目标依次为 `5、6、7、8、10、12、14、16` 回，大色块和连锁可以更快推进关卡。
- 难度会通过目标数、限时和撤离预警逐层递进；预警从 6.0 秒逐步缩短到 4.6 秒，玩家可以围绕闪烁区域继续改色，把更多相邻格并入同一次塌陷。
- 达到目标后会立即冻结关卡计时，但不会锁住移动；玩家仍可躲避尚未结束的爆破，待方块全部补回后再进入下一层。
- 六种奖励完全按同一次爆破最终包含的格子数确定：4 格金币、5 格蓝宝石、6–7 格红宝石、8–9 格祖母绿、10–11 格钻石、12 格及以上金条。闪烁或逐格爆破期间补连的同色格会计入最终数量；最后一格开始塌陷后才结算并必定生成奖励，不再受随机概率或连锁层数影响。

## 本轮修复

- 角色弹跳升级为四段式软胶动画：起跳前压扁蓄力、离地快速拉伸、弧线顶点恢复圆润、落地再次压扁并阻尼回弹；连续滑动会继承上一跳的落地形变，脚下方块同步加强压缩和回弹，不增加单格移动时长。
- 开始页 Logo 使用紧凑高对比版本并扩大手机端显示宽度；“开始游戏”箭头改用重新裁切的居中素材，不再受原图透明留白影响。
- 手机首次引导改为玩家点击开始后叠加在真实游戏界面内：棋盘、角色和 HUD 始终可见，三步提示全部由界面元素与动画完成，不再切换到独立教程图；引导期间冻结倒计时和输入，结束后无缝恢复本局。
- 战役由 3 层扩展为 8 层，关卡名称、目标、限时、难度和预警时长集中在 `game-config.mjs`，方便继续调数值。
- 点燃后的撤离时间整体放慢，爆破蓄力与逐格坠落也增加停顿和错峰，不再刚连成四格就迅速塌陷。
- 手机端相机保持约 53° 俯角，并绕棋盘旋转为非对称方位：一组边更接近水平、另一组边更陡；移动端相机基准距离进一步缩短到 15.6，取景中心横向补偿 -0.38，彩色棋盘在上一版基础上再放大约 6%，390×844 下更接近全宽，320×568 仍保留必要边距。
- 声音按钮在桌面、平板和手机断点下都与相邻“下一组”底板等高；451×912 手机尺寸下二者上下边缘与中心线完全对齐。
- 结束或重开时会清理延迟奖励与弹窗任务，避免跨局残留。
- 不再允许向已经塌陷或正在生长补回的格子起跳；棋盘边缘也不会误跳出界。
- 初始棋盘随机生成后保证不会自带四方向连通的四格同色组合。
- 玩家被爆炸命中时，危险格与角色会一起下落并扣除一条生命，随后在安全格复位；关卡、分数和剩余时间不会重置。
- 手机端移除常驻四向键，只保留全棋盘滑动；短滑单步、持续滑动连续跳，松手立即停止。
- 四连点燃后会播放逐渐加速的短促提示音，爆破前加入短暂蓄力停顿；危险格按中心向外的波纹顺序弹落，并随链反层数增强冲击波、音高和镜头反馈。
- 配乐改为 8 小节轻盈错拍循环，低频在 210Hz 以下做了清理，并取消固定 kick；倒计时、补格生长、扣除生命、单层完成、时间耗尽、最终失败与全部通关都有独立反馈音，关闭声音、重新开启和结束游戏时会平滑淡入淡出。
- 顶部只保留关卡、分数、时间、下一组和声音；品牌牌、装饰图标、叶片、贴纸和常驻移动键全部移除。状态栏、进度、提示和结算统一为无外描边、无硬投影的暖白平面；手机端保留下一组，并适配 320px 窄屏。
- 顶栏改为按同一条垂直中线排布；声音图标按钮清除浏览器默认内边距，在 320px 窄屏下与状态栏及“下一组”控件严格居中。
- 连通规则位于 `game-rules.mjs`。只有本次落地形成的四格及以上正交连通组会塌陷；独立同色格、纯对角线和新补回的格子都不会被连带点燃。自动测试覆盖直线、2×2、L/T 形、少于四格、棋盘边界和补格状态。
- 实际逐格塌陷节奏约放慢一倍：标准四格从爆破启动到最后一格下落由约 0.27 秒延长到约 0.54 秒；闪烁警告独立延长至 6.0–4.6 秒，补格速度保持不变。
- 角色单格跳跃由 0.31 秒缩短到 0.25 秒，持续滑动每 235ms 预排下一跳，保持更快且连贯的手机操作节奏。
- 苹果角色每次成功起跳会依次唱出“我是一颗小苹果 就爱跳跳乐”的一个字；连续跳跃按 12 字循环衔接，停顿超过 900ms 或进入新关卡后从“我”重新开始。歌声音节由公司 Audio Agent 生成并按真实发音位置切分为 12 个 0.25 秒 WAV，位于 `assets/audio/jump-lyrics`。
- 歌声使用独立人声通道，播放时会短暂压低 BGM，避免弹跳字音与配乐鼓点重叠；资源未加载完成或加载失败时自动使用原程序化弹跳音效，不影响游戏操作。
- v83 将原 118 BPM 拨弦式程序配乐替换为 Audio Agent 生成的原创 16 秒无明显拍点氛围循环 `assets/audio/mix-v83/happyjump-bgm-airy-loop.wav`；循环不含鼓组、节奏贝斯或固定音型，并清理 220Hz 以下频段，让每格歌词和落地反馈成为唯一的动作节奏。音频加载期间保持安静，加载失败时仅启用每四秒一次、慢起音的长音和弦兜底。
- 单关成功、全部通关、掉命、彻底失败和时间耗尽分别使用 `assets/audio/mix-v83` 中的五个原创采样；采样由 Audio Agent 生成后按有效声尾裁剪、转为单声道并做防爆音淡出，缺失时仍会回退到原程序化提示音。静音、重开和结算会停止残留采样，避免跨局叠音。
- v84 使用 Audio Agent 重新生成整套可爱玩具音色：16 秒背景循环以玩具钢琴、柔和木琴、卡林巴和气泡音为主，不含鼓组、掌声、明显拍点或人声，给逐格歌词留出节奏空间。五种结算提示音统一为同一音色世界，并按事件裁成 0.85 至 1.45 秒的短反馈；背景总线略降，歌词触发时压低得更深，连续跳跃时不会与配乐抢拍。
- v86 保留同一条连续清唱母带，但不再为每次跳跃重启平均切片。连续跳跃会延长同一条母带的播放门限，停跳时按真实发音边界柔和收尾；间隔跳跃则从对应完整发音边界起音，避免截断声母、重复起音和结巴感。
- v87 将“我是一个小苹果，每天就爱跳跳乐”改为 13.125 秒连续循环 BGM，不再逐跳切割人声；角色每跳一格只触发一个 90ms 软糖鼓点。跳跃动画与持续滑动间隔统一为 128 BPM 的八分音符（约 234ms），歌词保持完整连唱，操作仍然即时响应。
- v85 将跳跃歌词更新为“我是一个小苹果，每天就爱跳跳乐”。14 个字不再来自独立录音，而是共用 Audio Agent 生成的一条连续清唱母带；每次跳跃从母带对应位置取样，相邻音节以 45ms 交叉淡化衔接，连续跳时保持同一条气息和旋律，停跳时则自然收掉当前音节。

- v89 将跳跃、单层通关、全通关、掉命、彻底失败和时间耗尽统一替换为同一套“软糖果冻 + 玩具玻璃 + 轻巧木琴/拇指琴”音色，全部使用 Audio Agent 候选重新裁剪为手机端短反馈，资源位于 `assets/audio/mix-v89`；每个 WAV 为 48kHz、16-bit、单声道，并带短淡入淡出，避免键盘式 click、刺耳高频和不同来源音色拼接感。
- v89.1 修复爆破链在不同 warningId 之间错误合并的问题，并限制一次爆破至少保留一个可逃生格，避免整盘方块同时进入塌陷状态。
- v90 使用 Audio Agent 生成的欢乐音效套件替换整套动作反馈：跳跃是 150ms 的果冻“啵啾”加明亮上扬音符，通关、全通关、掉命、失败和时间耗尽分别使用同一套玩具木琴、卡林巴、玻璃铃与软糖气泡音色；所有采样为 48kHz、16-bit、单声道 WAV，短促清晰，适合手机连续触发，资源位于 `assets/audio/mix-v90`。
- v91 针对刺耳问题重新制作整套声音：BGM 改为 16 秒热闹的木琴/马林巴、玩具钢琴、圆润贝斯和柔和手鼓派对循环；高频做柔化、峰值降低，跳跃和结算音效统一为温暖圆润的 16-bit PCM WAV，并降低游戏内播放增益，资源位于 `assets/audio/mix-v91`。

- v92.1 将爆破奖励固定锚定在本次爆破区域的中心格：爆破完成后奖励保留在原位置，补生格子从棋盘内部长出时会把奖励一起抬起，不再随机跳到其他格子。
